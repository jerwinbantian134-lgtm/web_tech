HTML Text Formatting

HTML stands for HyperText Markup Language.

Tag Explanations

<b> - Bold

The <b> tag makes text bold without adding extra importance.

Example: This is bold text.

Example: This is bold text.

<strong> - Strong Importance

The <strong> tag marks text as important. Browsers display it in bold.

Example: Warning: Save your work before closing.

<i> - Italic

The <i> tag makes text italic.

The <i> tag displays text in italics, such as for technical terms or thoughts.

Example: The ship was named Endeavour.

<em> - Emphasis

The <em> tag emphasizes text. Browsers display it in italics.

Example: You must submit the lab today.
